
# Nexora Technologies — Company Website

A modern, responsive, four-page company website created for the WeIntern Full Stack Development Week 2, Task 1 assignment.

## Website Pages

### 1. Home
- Modern hero section
- Company introduction
- Service highlights
- Approach and working principles
- Call-to-action section

### 2. About
- Company story
- Core values
- Team profiles
- Company introduction

### 3. Services
- Digital strategy
- Product and UX design
- Web development
- Ongoing support
- Project development process

### 4. Contact
- Contact information
- Contact form
- Form validation
- Inline error messages
- Submission feedback

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Navigate through Home, About, Services and Contact.

No npm installation or build process is required.

## Contact Form Note

The contact form validates user input in the browser and displays feedback messages.

It is a frontend demonstration only. It does not send emails or store submitted information. A backend API or trusted form service is required for actual message delivery.
